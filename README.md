# CAMELYON16 slide-level robustness study

Follow-up to [encoder-or-probe](https://github.com/dinakar0745/encoder-or-probe). That study
measured patch-level linear probes under synthetic degradation. This one asks whether the gap
between a clean-trained and a mixed-trained head survives at slide level, on lymph-node
metastasis detection in CAMELYON16, when the head is a multiple-instance aggregator.

Status: pipeline under construction. No results yet.
